 FASE 3 — MÓDULOS DE NEGOCIO (EN ESTE ORDEN)

    -> Crear (POST), editar (PATCH), borrar (DELETE)

 8. Facturas de venta
    -> Lista paginada (GET /invoices/sales/list)
    -> Crear manualmente (POST /invoices/sales)
    -> Editar (PATCH /invoices/sales/{id})

 9. Facturas de compra
    -> Mismo patrón que ventas (/invoices/purchase)

10. Carga por OCR (feature principal, dejar para el final)
    -> Subir archivo: POST /invoices/extract (multipart, campo "file")
    -> Mostrar borrador editable (InvoiceDraft)
    -> Al confirmar: POST /invoices/sales o /invoices/purchase

11. Cobros y pagos
    -> Desde el detalle de factura:
       POST /payments/collection (cobros de ventas)
       POST /payments/payment   (pagos de compras)
    -> Ver historial, editar (PUT), eliminar (DELETE)
    -> El back recalcula el estado de la factura solo
